# Bakım ve Onarım Bilgi Sistemi

BLM3722 Yazilim Muhendisligi dönem projesi.

## Özellikler

- Müşteri bakım/onarım talebi oluşturur.
- Talep ekip liderine atanır.
- Ekip lideri departman ve kişi sayısı seçer.
- Sistem uygun teknik çalışanları atar.
- Teknik çalışan ek bilgi isteyebilir veya işini tamamladığını bildirir.
- Ekip lideri çözümü müşteriye gönderir.
- Müşteri çözümü onaylar, reddeder ve puan verir.
- Yönetici rapor görüntüler, çalışan/departman/ekip lideri yönetir.
- Veriler XML dosyalarında saklanır.

## Giriş Bilgileri

- Yönetici şifresi: `admin123`
- Ekip lideri şifresi: `4321`
- Teknik çalışan şifresi: `1234`

## Kullanılan Teknolojiler

- Java
- Java Swing
- XML
- Eclipse IDE
